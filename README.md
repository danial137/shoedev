# 👟 ShoeDev — Modern E-commerce Store

A modern and responsive **e-commerce web application** built with **Next.js, React, TypeScript, and Tailwind CSS**.

ShoeDev is focused on creating a clean and interactive shopping experience for browsing footwear products, viewing product details, selecting product options, and managing items in a shopping cart.

🔗 **Live Demo:** https://shoedev-eight.vercel.app
💻 **GitHub:** https://github.com/danial137/shoedev

---

## ✨ Overview

**ShoeDev** is a frontend-focused e-commerce project designed to simulate a modern online footwear store.

The project was built to practice real-world frontend development concepts such as reusable components, client-side state management, form handling, responsive design, product interactions, and modern Next.js application architecture.

The main focus was not only on building the UI, but also on creating a structured and maintainable frontend application.

## 🏗️ Architecture

The project follows a component-based architecture using the Next.js App Router.

The application is structured around reusable UI components and separates different responsibilities such as:

```text
shoedev/
│
├── public/
│
├── src/
│   ├── app/
│   │   ├── ...
│   │
│   ├── components/
│   │   ├── ...
│   │
│   ├── store/
│   │   ├── ...
│   │
│   └── ...
│
├── package.json
├── tsconfig.json
├── next.config.ts
├── postcss.config.mjs
└── README.md
```

This structure makes it easier to maintain the application and add new features as the project grows.

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm / pnpm / yarn

### Installation

Clone the repository:

```bash
git clone https://github.com/danial137/shoedev.git
```

Navigate to the project:

```bash
cd shoedev
```

Install dependencies:

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```

---

## 📦 Build for Production

Create a production build:

```bash
npm run build
```

Run the production server:

```bash
npm run start
```
